# Browser prototype

Open `index.html` directly in a browser. This standalone prototype shows the
Atelier dial only; it predates the native app's current options and other designs.
`Paper.png` and `Night.png` are reference renders of this prototype.

Like the native clock, it cross-fades to a slightly different position every five
minutes. Reduce Motion changes the position without a dissolve.

The native app and screensaver do not load these files.
